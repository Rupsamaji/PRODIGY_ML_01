# House Price Prediction using Machine Learning

This project builds a machine learning model to predict house prices based on property features such as area, number of bedrooms, and bathrooms.

## Project Overview
The goal of this project is to apply supervised machine learning techniques to estimate housing prices using historical data.

## Features
- Data preprocessing
- Feature selection
- Linear regression model
- Price prediction based on input parameters

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Workflow
1. Data collection
2. Data preprocessing
3. Model training using Linear Regression
4. Model evaluation
5. Price prediction

## Applications
- Real estate price estimation
- Property investment analysis
- Market trend prediction
